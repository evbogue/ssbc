# Decent workspace iteration

The before directory captures the running app before this iteration, at 1440px and 375px on decent2, ssbski, and ssbpro. The after directory records the new default workspace, repository views, dark mode, and compatibility skins.

The Anbot skin takes the ANBot study's warm surfaces, charcoal accent, persistent navigation, and quiet borders. Repositories become primary navigation on all skins. Decent keeps signed-feed activity, private messages, notifications, keys, working post actions, and its existing Git browser. Phones use bottom navigation and retain connect, settings, and profile access in the header.

The Anbot skin hides the discovery column and redundant large branding to give the workspace more room. Discovery itself works; it remains available in the other skins. The inspected post action controls have handlers (raw view, local save, copy link, more menu), so they were retained. No illustrative ANBot sync indicators or pretend coding controls were introduced.

Verification used read-only browsing on the live node, with no publishing or reaction clicks. Feed scrollWidth equals clientWidth at desktop and 375px on all three network skins. The shared bundle was rebuilt and checked for the new workspace brand. Test results are reported in the change's delivery note; server integration failures must not be interpreted as passing tests.

Anbot is now a separate selectable theme. The original decent2 stylesheet is restored; the default remains decent2. The theme picker uses two columns at half-screen widths and stays within the viewport.
